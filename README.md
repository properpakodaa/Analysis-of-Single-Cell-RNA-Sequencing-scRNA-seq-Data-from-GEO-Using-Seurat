Industry-Grade Single-Cell RNA-Seq Quality Control

Welcome to my bioinformatics project! In this project, I processed raw single-cell RNA sequencing data from dataset GSE279086 containing 40 human samples.

What I did:

Used Bash scripting to automatically download and rename genetic data files.

Used R and the Seurat package to organize the data into manageable digital objects.

Applied advanced statistical filtering (including Mahalanobis Distance) to filter out dead cells, empty cells, and machine errors.
